## 🇺🇸 English

### Design system unification
- **Single color palette** `COLOR.*` tokens (lib/ui/tokens.ts) — one source of truth replacing inline `rgba()`/`#hex` literals. Includes ink/paper, hover/accent/tint, shadows, dark-theme pairs, brand accents (appleRed, heartRed, liveGreen), and a 3-color medal palette
- **2-tier font system** — Title 16, Body 12 (both multiples of 4). Hero 16/600, row titles 12/500–600, captions 12/400, eyebrows 12/600 with uppercase tracking
- **4-multiple box grid** — every padding/margin/gap/width/height/borderRadius snaps to 4·8·12·16·24 tokens via sweep
- **HEART_RED policy** — the only chromatic accent allowed in the monochrome system (filled-heart liked state, heart count meta)

### Right-rail alignment system
- **Symmetric 12-px gutters** — left + right both use body padding 12 + row padding 12 → content edges at panel-x=24 and panel-right−24
- **HIG touch targets** — all trailing buttons bumped 28→32, cluster gap 2→4
- **Unified trailing column** — Plus / Check / Ellipsis / Heart icon all in 32-wide center slots, counts in 32-wide center slots
- **Up Next telescoping panel** — expanded queue floats as absolute overlay, body layout untouched
- **Now-Playing EQ indicator** — 3-bar CSS animation (`NowPlayingEQ`) with `prefers-reduced-motion` support

### Reactive rail layout
- **CSS variable broadcast** — `--vbk-left-rail-w` / `--vbk-right-rail-w` update live on resize / collapse
- **NowPlayingBar auto-centering** — `calc(leftRail + (vw - rails) / 2)` keeps the bar at the midpoint between rails at any width
- **Camera frustum panning** — `setViewOffset(dx, 0)` shifts the rendered scene so buildings stay aligned with the bar's center (canvas itself stays pinned to the viewport — no exposed edges)
- **Rail transparency fade** — alpha 0.40 → 0.02 (blur-only) as the user drags wider

### Toast & search
- **Toast system** — `lib/ui/toast.ts` pub/sub + `ToastHost` bottom-center HUD for quiet status (e.g. "Already in your playlist")
- **Curator search** — search composer matches `@alias` / curator name / playlist name substring; matches surface above track results in a dedicated `Playlists` section → click opens PlaylistDetailView

### Landing-page cinematic intro

- **Blur + scrim fade-in** + **staggered content reveal** (1700–2300 ms in 4 steps)
