# 작업 로그 (today)

날짜별로 이 폴더 아래에 정리합니다.

## 규칙

- 하루 단위 폴더: `YYYY-MM-DD/` (예: `2026-04-11/`)
- 그 안에 역할별 파일:
  - **`front.md`** — vibloc-front 관련
  - **`backend.md`** — vibloc-backend 관련
- 작업할 때마다 해당 날짜 폴더의 파일에 **짧은 bullet**으로 추가하면 됩니다.
- 팀원 수준이 다를 때: **개발자용 요약** + **비개발자(현태 등)용 쉬운 말** + **Claude Code에 붙여 넣을 프롬프트 예시**를 같은 날짜 파일에 적어 두면, 나중에 AI에게 맥락을 넘기기 쉽습니다.

전날 이어서 쓸 때는 같은 날짜 파일에 이어 쓰거나, 새 날이면 새 폴더를 만듭니다.
