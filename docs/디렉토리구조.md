# VIBLOC 디렉터리 구조

**원칙:** 레포 루트에는 **빌드·패키지 설정 + `CLAUDE.md` + `README.md`** 만 두고, 문서는 **`docs/`**, 데이터 수집 스크립트는 **`scripts/data/`**, 앱 코드는 **`src/`**, 정적 자산은 **`public/`** 에 둔다.

---

## 레포 루트 (최소 유지)

| 경로 | 역할 |
|------|------|
| `package.json` / `package-lock.json` | npm 의존성·스크립트 |
| `vite.config.ts` | Vite + React + Tailwind |
| `tsconfig*.json` | TypeScript |
| `eslint.config.js` | ESLint |
| `index.html` | Vite HTML 엔트리 |
| `.env.example` | 선택적 환경 변수 (예: Google Maps Embed 키) |
| `.gitignore` | Git 제외 |
| **`CLAUDE.md`** | 프로젝트 마스터 컨텍스트 (도구가 루트에서 찾는 경우가 많아 여기 유지) |
| **`README.md`** | 한 줄 소개·실행 방법·문서 링크 |
| `bun.lock` | Bun 사용자용 (선택). 기본 워크플로는 npm. |
| `docs/` | 모든 마크다운·PDF 문서 |
| `scripts/` | Python·쉘 등 유지보수 스크립트 |
| `public/` | 빌드 시 그대로 노출되는 정적 파일 |
| `src/` | React / R3F 애플리케이션 |
| `.claude/` | Claude Code 로컬 설정 |

## `scripts/`

| 경로 | 설명 |
|------|------|
| `README.md` | 스크립트 실행 안내 |
| `data/*.py` | `public/data`용 데이터 다운로드·보강 (Overpass, Nominatim, Wikidata …) |
| `build_brand_blocklist.py` | `src/data/brandBlocklist.json` 생성 |
| `start-dev.sh` | (선택) Bun dev — 보통은 `npm run dev` |

---

## `public/` (URL로 그대로 제공)

- `favicon.svg`, `icons.svg`
- `data/` — 도시별 OSM·지형·POI·위키 보강 JSON

---

## `src/` (애플리케이션)

```
src/
├── main.tsx, App.tsx, index.css
├── assets/
├── types/index.ts
├── data/                    # genres, brandBlocklist (런타임 소형 데이터)
├── stores/                  # Zustand
├── components/
│   ├── canvas/              # R3F / Three
│   └── ui/ (+ ui/music/)
└── lib/
    ├── app/                 # i18n, demoSeed
    ├── geo/                 # OSM, 지오코딩, 건물 생성, tasteEngine …
    ├── streetview/
    ├── scene/               # sunPosition
    ├── weather/
    └── music/ (+ music/sources/)
```

### `lib/` 역할 요약

| 디렉터리 | 예시 |
|----------|------|
| `lib/app/` | `i18n.ts`, `demoSeed.ts` |
| `lib/geo/` | `osmLoader.ts`, `buildingGen.ts`, `geocoder.ts`, `plusCode.ts`, `tasteEngine.ts` … |
| `lib/streetview/` | 키, 뷰포인트, Commons 사진, `subwayAvoid` |
| `lib/scene/` | `sunPosition.ts` |
| `lib/weather/` | `openMeteo.ts` |
| `lib/music/` | iTunes, 추천, 플레이리스트 |
