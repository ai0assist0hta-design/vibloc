## 4. 비주얼 디자인 시스템

```ts
COLOR = {
  ink: '#...',          // 본문 텍스트
  ink2: '#...',         // 보조 텍스트
  paper: '#...',        // 배경
  hover: 'rgba(...)',   // 호버 톤
  divider: 'rgba(...)', // 경계선
  accent: '#...',       // 액센트 (절제된 사용)
  // 다크 페어
  paperDark: '...',
  hoverDark: '...',
}
```

원칙: {예 — "monochrome 시스템에서 brand red는 ♥ 좋아요에만 사용"}

### 타이포그래피

| 토큰 | 크기/굵기 | 용도 |
|---|---|---|
| HERO_HEADLINE | 16/700 | 큰 카드 제목 |
| ROW_TITLE | 16/600 | 행 제목 |
| ROW_CAPTION | 12/500 | 행 보조 |
| EYEBROW | 12/700 uppercase | 섹션 라벨 |

폰트 스택: `{font-family}`

### 간격 + 라디우스


## 9. 접근성 고려

- 키보드 네비게이션 — 모든 인터랙티브 요소 tabindex
